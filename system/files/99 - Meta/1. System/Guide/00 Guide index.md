## Conventions used in this guide

- **Bold** is a label exactly as it appears on screen.
- `Cmd/Ctrl + P` means `Cmd + P` on a Mac and `Ctrl + P` on Windows or Linux.
- A link such as [[02. Mission Deck]] opens the page being described.
- Links to Mira's notes stop working once you delete the examples. The instructions still apply to your own notes.
- This guide describes the desktop version. Sylvics does not run on phones or tablets.
