# Planning

After this page you can create a task, a project, a goal and a habit, and you will know how they connect.

> [!tip] The rule behind this page
> **The Finish Line Test** and **Status Is Location**: what you can finish belongs here, and you archive it by changing its status. All ten rules: [[The rules of the vault]].

## The four levels

Everything in `02 - Planning` sits on one of four levels. Open [[0. Planning Masterpage]] to see them side by side.

| Level | Folder | What it holds | Masterpage |
|---|---|---|---|
| Alignment | `1. ⚖️ Alignment` | Who you want to be: identity and personality statements, values, beliefs, memories, archetypes, affirmations | [[⚖️ 0. Alignment Masterpage]] |
| Strategy | `2. ♟️ Strategy` | What you are aiming at and practising: goals, habits, skills | [[♟️ 0. Strategy Masterpage]] |
| Execution | `3. 🚀 Execution` | What you are doing: projects, tasks, and the log of decisions made | [[0. 🚀 Execution Masterpage]] |
| Later | `4. 🌌 Latent` | What is not active yet: ideas, decisions still to make, the bucket list | [[🌌 0. Latent Masterpage]] |

You can start at any level. Most people start with tasks and one project, and write goals a week or two later. Nothing forces you to write an identity statement first.

## Create a task

1. Open [[📌 0. Tasks Masterpage]].
2. Click **➕ CREATE NEW TASK**.
3. Type the task under **What is the task?** and click **Save**.

The task is created as `📌 <your words>.md` in the Tasks folder, with **Status** set to `📋 Queued`, and it opens. The coloured fields at the top are its header. Click a field to change it:

| Field | Choices or format |
|---|---|
| **Status** | `📥 Inbox`, `🗃️ Latent`, `📋 Queued`, `📅 Scheduled`, `⚡ Active`, `⏸️ Paused`, `🤝 Delegated`, `⏳ Waiting`, `✅ Completed`, `🛑 Archived` |
| **Priority** | `🔴 P1`, `🟠 P2`, `🟢 P3` |
| **Energy** | `🔋 Charging`, `⚖️ Neutral`, `🪫 Draining` |
| **Time Est.**, **Scheduled**, **Deadline**, **Completed** | A duration and three dates |
| **Recurrence** | Daily, Weekly, Monthly, Yearly |

Below the header, under **Alignment**, the **Project** and **Goal** lists link the task to what it serves. A task linked to a project shows on that project's board.

When a task is done, set **Status** to `✅ Completed`. When you set it to `🛑 Archived`, the note moves to `08 - Archive` by itself. Set it back to an active status and it returns.

For a worked example, open [[📌 Audit which carrier data we actually hold]].

## Create a project

A project is a piece of work with an end and more than one task.

1. Open [[📂 0. Projects Masterpage]].
2. Click **➕ CREATE NEW PROJECT**.
3. Type the name under **What is the name of this project?** and click **Save**.

The project is created as `📂 <name>.md` with **Status** `⚪ Not Started`. On the project page:

- Set **Status**, **Deadline** and **Progress** in the header.
- Link it to a goal under **Associated Goals**.
- Use **CREATE TASK** on the execution board to add tasks that belong to it.
- The second tab, **Execution & Strategy**, has boxes for **Success Criteria**, **Constraints and Risks** and **The Outcome**. Two lines in each are enough.

Example: [[📂 Carrier Scorecards discovery]].

## Create a goal

1. Open [[🎯 0. Goals Masterpage]].
2. Click **➕ CREATE NEW GOAL**.
3. Type the goal under **What is the goal?** and click **Save**.

The goal is created as `🎯 <name>.md` with **Status** `🗺️ Planning`. Set the **Horizon** (the quarters it belongs to) and **Progress** in the header. The **Configuration** tab holds **The Outcome**, **The 'Why'**, **Success Criteria** and **Key Obstacles**, and the **Life Area** the goal belongs to. Projects and habits that link to the goal appear on its first tab without any work from you.

Example: [[🎯 Fill the sabbatical fund to 18,000 euros]].

## Create a habit

1. Open [[🔹 0. Habits Masterpage]].
2. Click **➕ CREATE NEW HABIT**.
3. Type the habit under **What is the habit?** and click **Save**.

Then set, in the header of the new habit:

- **Repetition**: the weekdays it applies to. A new habit starts on all seven.
- **Order**: its position in the daily list. 1 comes first.
- **Shutdown Ritual**: turn on if it belongs to the evening close and not to the day's habits.

From the next daily note you open, the habit is in the day's list. See [[02 Your day]]. Example: [[🔹 Walk before screens]].

## How the pieces connect

```
identity and values  →  goal  →  project  →  task
                          ↑
                        habit
```

- A **task** names its project and goal.
- A **project** names its goals.
- A **goal** names the life area it belongs to, and the identity it serves if you have written one.
- A **habit** names its goals and its area.

The links are what make the dashboards work. [[02. Mission Deck]] lists open tasks with their project. Each area page in [[04 Your life areas]] lists the goals, projects and tasks that name that area. A note with no links still works. It just appears in fewer places.

## Archiving

In every planning type, choosing the archived status (for example `🛑 Archived`) moves the note to the matching folder in `08 - Archive`. Each masterpage has a link to its archive at the bottom, such as **🗃️ Access Archived Goals**. It opens [[0. Archive Masterpage]]. You can also browse `08 - Archive` in the file explorer.
