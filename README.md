# Sylvics Live Vault

The public side of Sylvics, the Obsidian vault for your whole life. The Sylvics Core plugin reads this repository from **Settings → Sylvics Core → Git**. No GitHub account is needed.

## What is here

- `library/`: notes you can bring into your vault one by one (literature, resources, permanent notes), in folders that mirror the vault's, so each note lands in its own home. Each note shows a preview before you import it, and a note you have edited is never overwritten.
- `system/`: the pages that belong to Sylvics itself (masterpages, templates, the guide, the art) and how each one updates, read by **Check for updates**. Your own notes are never part of it.

The Sylvics Core plugin itself is not in this repository. It comes with your licence.
