# Sylvics Library: resources

> [!info] A placeholder
> This note holds the place of the resources the Sylvics library will offer. Delete it whenever you like: deleting it changes nothing else, and it is never brought back.

**What will be here.** Reference material that is useful to keep in a vault: checklists, templates for common situations, how-tos, and reference sheets. Each one lands in the right folder of `04 - Resources`.

**How you will use them.** Pick what you need in **Settings → Sylvics Core → Updates & library → Library**, preview it, import it. The **Library Index** lists everything you brought in, and **Check the library** tells you when a newer version is out.

**What stays yours.** A resource you edit is never overwritten by an update.
