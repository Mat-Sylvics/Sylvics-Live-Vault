# Cheat sheet

One page to keep open. `Cmd/Ctrl` means `Cmd` on a Mac and `Ctrl` on Windows or Linux.

The ten rules behind it all are on one page: [[The rules of the vault]].

## The loop

| When | Do | Where |
|---|---|---|
| Any time | Capture a thought | [[01. Braindump]] → type → **Send to the inbox →** (`Cmd/Ctrl + Enter`) |
| Morning, 2 minutes | Open today's note, write the one outcome | `Cmd/Ctrl + D` |
| During the day | Tick habits, work from the task list | Today's note, [[02. Mission Deck]] |
| Evening, 5 minutes | Summary, rating, tomorrow's win, shutdown list | Today's note |
| Weekly, 30 minutes | Empty the Inbox, write the weekly review | [[02. Inbox Processing]], calendar → **W** button |

## Where things go

Stop at the first yes.

| Is it... | Folder | Created from |
|---|---|---|
| Just captured, undecided | `01 - Inbox` | [[01. Braindump]] |
| A task | `02 - Planning` | [[📌 0. Tasks Masterpage]] → **➕ CREATE NEW TASK** |
| A project | `02 - Planning` | [[📂 0. Projects Masterpage]] → **➕ CREATE NEW PROJECT** |
| A goal | `02 - Planning` | [[🎯 0. Goals Masterpage]] → **➕ CREATE NEW GOAL** |
| A habit | `02 - Planning` | [[🔹 0. Habits Masterpage]] → **➕ CREATE NEW HABIT** |
| An ongoing part of life | `03 - Areas` | The tool pages of each area. See [[04 Your life areas]]. |
| Someone else's work, or a reference fact | `04 - Resources` | The masterpage of its type. See [[05 Knowledge]]. |
| My account of one source | `05 - Literature` | [[📖 0. Literature Masterpage]] → **➕ Create New Literature Note** |
| One idea of my own | `06 - Permanent` | [[💎 0. Permanent Masterpage]] → **💎 Create New Permanent Note** |
| A day or a review | `07 - Journal` | The Sylvics calendar, and the buttons at the top of journal notes |
| Finished | `08 - Archive` | Set the note's status to archived. It moves by itself. |

## Commands

Press `Cmd/Ctrl + P` and type part of the name.

| Command | What it does |
|---|---|
| **Open Sylvics Canopy Graph** | Opens the graph |
| **Open Sylvics Canopy Graph (Classic)** | Opens the earlier graph |
| **Sylvics Core: Open Sage Chat (Fullscreen)** | Opens the Sage chat as a page |
| **Sylvics Core: Open Sage Chat** | Opens the Sage chat in the right sidebar |
| **Sylvics Core: Open Braindump** | Opens the capture box in the right sidebar |
| **Sylvics Core: Open Chronos Timer** | Opens the focus timer in the right sidebar |
| **Sylvics Core: Open Ambient Player** | Opens the music player in the right sidebar |
| **Sylvics Core: Open Example Files Index** | Opens the list of example notes, for deleting or keeping |
| **Sylvics Core: Toggle Still-Mode** | Turns animations and heavy effects off or on |
| **Sylvics Core: Force Refresh** | Rebuilds the graph data |
| **Run Vault Doctor** | Checks that the core folders exist and can recreate missing ones |
| **Sylvics Core: Check for plugin and theme updates** | Lists community plugins and installed themes that have a newer version and asks before updating them |
| **Sylvics Core: Open Start Here** | Opens the ten-minute tour |
| **Sylvics Core: Sweep Large Files Now** | Moves files over 95 MB to the large-media folder now |
| **Sylvics Core: Insert Sylvics Banner** | In an open note, inserts the block that draws a Sylvics header |

The sidebar commands need the sidebar to be visible. On a full-screen page, click **⛶** first.

Development copies of the plugin also list three developer tools: **Dump Graph to Console**, **Show Last Timing** and **Test AI Semantic Search**. The beta build does not include them.

Useful Obsidian commands with no shortcut: **Delete current file**, **Move current file to another folder**, **Templater: Create new note from template**.

## Shortcuts

The first three are added by this vault. The others are Obsidian's own and work as in any vault.

| Keys | Action |
|---|---|
| `Cmd/Ctrl + D` | Open today's daily note, creating it if needed |
| `Cmd/Ctrl + Shift + H` | Open the Homepage |
| `Cmd/Ctrl + R` | Reload Obsidian |
| `Cmd/Ctrl + O` | Quick switcher: open any note by name |
| `Cmd/Ctrl + P` | Command list |
| `Cmd/Ctrl + ,` | Settings |
| `Cmd/Ctrl + E` | Switch between reading and editing |
| `Cmd/Ctrl + Shift + F` | Search all notes |
| `Cmd/Ctrl + F` | Find in the current note |
| `Cmd/Ctrl + N` | New empty note at the top of the vault |
| `Cmd/Ctrl + W`, `Cmd/Ctrl + T` | Close the tab, new tab |
| `Cmd/Ctrl + K` | Insert a link |
| `Cmd/Ctrl + B`, `I` | Bold, italic |
| In the graph: `1`–`9`, `Space`, `F`, `H`, `/`, `C`, `Esc` | Views, play, focus, starting view, search, hide the interface, step back (see [[08 The graph]]) |

`Cmd/Ctrl + D` is Obsidian's key for **Delete paragraph**; in this vault it opens the daily note instead. Change any key under **Settings → Hotkeys**.

## How notes are named

The emoji comes first, then a space, then the name. Create buttons add the emoji for you.

| Type | Looks like |
|---|---|
| Jot in the Inbox | `✏️ Jot - buy lamp bulb, cat food, stamps` |
| Task | `📌 Book the Lisbon flights` |
| Project | `📂 Home office in the spare room` |
| Goal | `🎯 Reach 2,500 newsletter subscribers` |
| Habit | `🔹 Read 20 pages` |
| Skill | `♦️ Climbing technique` |
| Decision made, decision open | `📜 ...`, `❓ ...` |
| Idea, bucket-list item | `🔍 ...`, `⭐ ...` |
| Book, article, podcast, paper | `📕 ...`, `📰 ...`, `🎙️ ...`, `🔬 ...` |
| Quote, concept | `💬 ...`, `🧩 ...` |
| Literature note | `📖 Author on subject` |
| Permanent note | `💎 A full statement of the idea` |
| Person | The plain name: `Jonas Reuter` |
| Masterpage | Starts with `0.` or `00.` |

| Journal note | File name | Example |
|---|---|---|
| Daily | `YYYY-MM-DD-Weekday` | `2025-10-24-Friday` |
| Weekly | `YYYY-Www` | `2025-W20` |
| Monthly | `YYYY-MM-Month` | `2025-05-May` |
| Quarterly | `YYYY-Qn` | `2025-Q2` |
| Yearly | `YYYY` | `2025` |

## Seven rules

1. Capture first, decide later. Everything new goes to the Inbox.
2. Empty the Inbox once a week.
3. Create a note with the button for its type, so that it lands in the right folder with the right layout.
4. One idea per permanent note, and its title is a statement.
5. Link a task to its project, and a project to its goal.
6. Archive by changing the status. Do not delete finished work.
7. Leave the ten folders, the masterpages and the templates' names as they are.
