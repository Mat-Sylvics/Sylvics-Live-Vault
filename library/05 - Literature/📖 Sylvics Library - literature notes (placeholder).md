# Sylvics Library: literature notes

> [!info] A placeholder
> This note holds the place of the literature notes the Sylvics library will offer. Delete it whenever you like: deleting it changes nothing else, and it is never brought back.

**What will be here.** Notes on books, articles, talks and courses, written the Sylvics way: what the source says, in plain words, with the passages that matter and where to find them. Each one is a finished literature note, ready to link to your own permanent notes.

**How you will use them.** Browse the library in **Settings → Sylvics Core → Updates & library → Library**, preview a note, and import only the ones you want. Each lands here in `05 - Literature`, next to your own. The **Library Index** lists every note you brought in.

**What stays yours.** Once a note is imported you can edit it freely. An update never overwrites a note you changed.
