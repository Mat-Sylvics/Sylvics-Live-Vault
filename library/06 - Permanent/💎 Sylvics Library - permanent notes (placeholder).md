# Sylvics Library: permanent notes

> [!info] A placeholder
> This note holds the place of the permanent notes the Sylvics library will offer. Delete it whenever you like: deleting it changes nothing else, and it is never brought back.

**What will be here.** Ideas stated in one sentence and argued in a few paragraphs, each linked to the literature notes it comes from. They are examples of what a permanent note can be, and starting points you can disagree with, rewrite or connect to your own.

**How you will use them.** Import the ones that speak to you from **Settings → Sylvics Core → Updates & library → Library**. They land here in `06 - Permanent`, appear in the graph and the Knowledge pipeline, and the **Library Index** keeps track of them.

**What stays yours.** Your own permanent notes are never touched. An imported note you edit is never overwritten by an update.
